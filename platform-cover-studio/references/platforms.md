# Platforms

## wechat-cover
- Size: `900x383`
- Use for公众号头图 / 分享封面
- Best with `editorial-minimal`
- Keep title compact; validation checks the safe area

## wechat-article
- Output: standalone HTML
- Template: `wechat-article-clean`
- Best when the Markdown source already has blocks, quotes, and lists

## xhs-cover
- Size: `1200x1600`
- Default template: `editorial-cover`
- Default acceptance direction is the clean gradient baseline; use `comic-explainer` only when the brief explicitly wants louder speech-bubble energy

## x-post
- Size: `1600x1200`
- Default template: `editorial-cover`
- Best for magazine-cover energy and concise summary copy
